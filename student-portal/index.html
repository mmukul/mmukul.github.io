🚀 Setup Your DevSecOps Lab

Prepare the VM once, then run the installer and select the lab type you need.
1Create the VMInstall VirtualBox and create a Rocky Linux VM with 1 CPU, 8 GB RAM and 40–60 GB disk.
2Configure NetworkSet the VirtualBox network adapter to Bridged Adapter.
3Run the InstallerRun the command below inside Rocky Linux and choose Master, Slave, Master-Slave or Full DevSecOps Lab.
4Verify & LearnVerify the installed services, open Jenkins where applicable and start your hands-on practice.

curl -fsSL https://raw.githubusercontent.com/mmukul/devsecops-training-lab/main/nextgen-devsecops-setup.sh | sudo bash
